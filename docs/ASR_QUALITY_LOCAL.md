# Subtitle-AUTO 로컬 ASR 품질 모드 (Alt+S)

기존 Windows 로컬 환경용 문서이며, 공개 ZIP/Setup 0.1.0에 포함됐다는 뜻은 아닙니다.

## 입력과 기존 기능
- 모델 선택 W=Whisper, Q=Qwen3-ASR, S=SenseVoice.
- 5번은 기존 화면 OCR OFF/속도/균형 설정. 7번은 Whisper 빠름/균형/정밀 설정.
- 7번 Beam Size: 빠름=1, 균형=5(기존값), 정밀=7. Qwen·SenseVoice 직접 선택에는 적용하지 않습니다.
- 최초 모델 로딩 중에도 5/7번을 선택할 수 있으며 첫 파일부터 반영됩니다. 실행 중 변경은 다음 파일부터 적용됩니다.
- 언어 기본값은 기존 config.json language:null을 유지하여 영어·일본어 한쪽으로 고정하지 않습니다.

## 정밀 교차검증
- Whisper의 낮은 신뢰도·반복·이상한 글자 밀도·영어/일본어 언어 전환 구간만 선택합니다.
- 파일당 최대 3개 구간, 각 최대 12초, 추출량 총 36초 이내. 짧은 파일에도 별도 제한을 둡니다.
- SenseVoice를 우선 독립 프로세스로 실행합니다. 원문과 유사하면 Qwen을 불러오지 않습니다.
- 큰 불일치가 있고 자동 교정 가능한 구간에만 Qwen을 실행합니다.
- 두 모델의 강한 합의가 있고 원래 Whisper 전사와 크게 다르며 인접 대사가 없는 경우만 텍스트를 수정합니다. 타임스탬프는 그대로 유지합니다.
- VRAM 부족·모델 실패·경계 불확실성·합의 부족이면 Whisper 자막을 그대로 유지합니다.
- 검토 기록은 해당 영상 폴더 아래 .subtitle-auto/asr-reviews에만 저장합니다. 기존 사용자 SRT를 덮어쓰지 않습니다.

## OCR·GPU
- OCR은 기존대로 음성 자막 뒤에 화면 문자를 합칩니다. 정밀+OCR에서는 OCR 미리 불러오기를 미뤄 GPU 메모리 경합을 줄입니다.

## 2026-10-24 합성 음성/영상 격리 시험
- RTX 5060 Ti 16GB, 약 11초 영어·일본어 음성.
- SenseVoice 독립 전사 약 39초, Qwen 독립 전사 약 61초(각 초회 로딩 포함).
- 선택한 의심 영어 구간을 실제 두 모델로 재검사해 잘못된 임시 자막을 교정하는 E2E: 약 88초.
- Whisper 세 Beam 모드 모두 성공. GPU 워밍업 후 이 짧은 샘플에서는 약 0.9~1.2초, 정확도·속도 차이는 자료에 따라 변합니다.
- OCR 속도 모드 합성 영상: 화면 글자 1개와 음성 자막 3개를 최종 4개로 병합 성공, 약 39초.
- 사용자 원본 영상, 운영 Alt+S, 원본 모델 및 실행 중인 BCT는 변경하지 않았습니다.

실제 영상에서의 정확도·속도 향상은 사용자 표본을 활용한 추가 비교가 필요합니다.

- 인접 대사와 겹쳐 자동 교정할 수 없는 구간은 메모리·시간을 낭비하지 않도록 보조 모델 실행 없이 검토 기록만 남깁니다.

## 기존 실제 벤치마크 음성 120초 구간 두 건 (2026-10-24)

- 실제 작업에서 사용하던 120초 음성 샘플 2개를 각각 균형(Beam 5)·정밀(Beam 7)로 재처리했고 모두 SRT 생성에 성공.
- 구간 1: 균형 39.50초, 정밀(최적화 전) 46.64초. 기존 다른 모델 자막과의 텍스트 일치도 95.80% → 96.13%, 검토 1건·자동 교정 0건. 비교용 자막은 사람이 검증한 정답이 아니므로 정확도 96%라는 뜻이 아니다.
- 구간 2: 정밀 24.48초(첫 추론), 균형 2.61초(뒤이어 실행). 비교용 자막과의 일치도 양쪽 모두 92.59%, 검토 0건·교정 0건.
- 순서에 따라 GPU 첫 추론 비용이 커 차이는 정밀 모드의 순수 오버헤드가 아니다. 같은 모델 워밍업 후 실제 처리시간을 따로 비교해야 한다.
- 겹친 대사는 자동으로 안전하게 교정할 수 없으므로 보조 모델 로딩을 생략하는 후속 최적화를 반영. 동일 구간 1에서 정밀 모드 시험 결과 22.58초, 의심 1건·모델 실행 0건·교정 0건·검토 기록 보존. 이 시간도 모델/캐시 워밍업 조건이 다르므로 엄밀한 A/B 우위 주장은 하지 않는다.
- 실제 정답을 사람이 검수한 표본이 없으므로 품질 향상률·오교정률 수치에 대한 수락은 보류. 대신 기능 E2E·원본 무결성·회귀 테스트 통과를 확인한다.
