# Privacy and model download

- User media and SRT files are processed and stored locally.
- Quickstart has no telemetry, analytics account, or media upload code.
- The selected Whisper model downloads from Hugging Face on first use;
  IP address and ordinary request metadata are visible to that provider.
- Model cache: LOCALAPPDATA/Subtitle-AUTO/models.
- Existing SRT files and original media are never overwritten by Quickstart.
- Uninstallation does not erase user model caches. Delete them separately if desired.
